# Tayseer Innovations — Premium Website Prototype

Interactive redesign prototype for [tayseer.me](https://www.tayseer.me/).

## Open locally

Double-click `index.html`, or from this folder:

```bash
start index.html
```

Or serve with any static server:

```bash
npx --yes serve .
```

## Prototype highlights

- Dark premium fintech aesthetic (navy / cyan / emerald)
- Particle neural background + cursor spotlight
- Interactive **Solutions** flow:
  1. Click a card → others hide
  2. Detail panel with visual + **Book a Demo** / **Back**
  3. Demo mode with phone carousel (MBuke), dashboards, ATM / cloud previews
- Fahim AI ecosystem graph
- Core banking architecture path lighting
- Animated stats, Gulf presence map, AI concierge contact chat
- Responsive: desktop / tablet / mobile

## Files

- `index.html` — structure
- `styles.css` — design system & animations
- `app.js` — interactions & demos
