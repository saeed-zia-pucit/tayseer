# Tayseer Product Finder (Prototype)

Interactive consultant-style prototype that recommends a Tayseer product stack from a short guided flow. No backend or AI APIs — deterministic mock recommendations.

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually http://localhost:5173).

## Flow

1. `/` — minimal landing  
2. `/finder` — two-column Product Finder (questions + live “Your Solution”)  
3. `/results` — recommended solution, architecture, timeline, CTAs  

## Stack

Vite · React · TypeScript · Tailwind CSS · React Router · Framer Motion
